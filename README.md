# Валютный кошелёк

Консольное приложение на Python для имитации работы валютного кошелька.
Репозиторий оформлен как устанавливаемый пакет; сейчас в нём подготовлены
окружение, CLI-каркас и настройки контроля качества.

## Требования

- Python 3.12 или новее
- [`uv`](https://docs.astral.sh/uv/)

## Подготовка окружения

```sh
uv sync
```

Запуск приложения из исходников:

```sh
uv run wallet
```

На этом этапе доступны команды `help` и `exit`. Основные операции кошелька будут
добавляться в следующих задачах проекта.

## Контроль качества и сборка

```sh
uv run ruff check .
uv run ruff format --check .
uv build
```

## Структура

```text
src/finalproject_nikolaev_m26_555/
├── cli.py       # интерактивная командная оболочка
└── main.py      # точка входа приложения
```

CLI разбирает пользовательский ввод через `shlex`. Для табличного вывода
подключён `prettytable`. В следующих этапах здесь появятся модель кошелька,
JSON-хранилище, операции с балансами и обмен валют, а также декораторы и
кэширование.
